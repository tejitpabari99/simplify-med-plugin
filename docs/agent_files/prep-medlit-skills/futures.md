# Deferred features

These features are outside the current scope, per the user's decisions on 2026-09-26. They are ideas to revisit, not commitments.

- Diagnosis generation.
- Treatment recommendations.
- Automated clinical triage.
- EHR integration.
- External medical information in patient-facing skill outputs. Research used to design an assessment is separate from this feature.
- Longitudinal patient records.
- Multilingual assessment.
- Custom HTML experiences; use basic output initially.
- Wiring the `med-lit` patient profile into other skills or pipelines to adapt their responses.

Individual health-literacy assessment is explicitly **in scope** for `med-lit`.
